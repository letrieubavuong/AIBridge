# Connecting ChatGPT Web to AIBridge MCP Server

This guide provides step-by-step instructions for connecting **ChatGPT Web** to the local **AIBridge Model Context Protocol (MCP)** server for Phase 08 end-to-end task orchestration.

---

## 1. Prerequisites

- **AIBridge WPF Application** built and running on Windows.
- **Antigravity CLI (`agy`)** installed and authenticated (optional for mock tests, required for real execution).
- A valid **API Token** generated by AIBridge (visible or regeneratable via AIBridge WPF UI).

---

## 2. Start AIBridge MCP Server

1. Open **AIBridge Desktop**.
2. Locate the **MCP SERVER** panel at the top of the window.
3. Click **[START MCP]** (if not automatically started).
4. Verify the status displays:
   - **Status**: `RUNNING (127.0.0.1:8788)`
   - **Endpoint**: `http://127.0.0.1:8788/mcp`
   - **Auth**: `ENABLED`

---

## 3. Temporary Secure HTTPS Tunnel (For Remote ChatGPT Web)

Because ChatGPT Web runs in the cloud, it cannot directly reach `127.0.0.1:8788` on your local Windows machine. A temporary secure HTTPS tunnel is required for external connectivity during test sessions.

### Using Cloudflare Tunnel (Recommended)
```bash
cloudflared tunnel --url http://127.0.0.1:8788
```
- Copy the generated public HTTPS URL (e.g., `https://random-subdomain.trycloudflare.com`).
- Your MCP streamable HTTP endpoint is now: `https://random-subdomain.trycloudflare.com/mcp`

> **Security Note**:
> - Never commit tunnel URLs or authentication tokens to source repositories.
> - Terminate the tunnel (`Ctrl+C`) immediately after completing your test session.
> - Regenerate your AIBridge API Token in WPF UI after public testing.

---

## 4. Connect to ChatGPT Web

1. Open **ChatGPT Web** (chatgpt.com).
2. Go to **Settings** -> **Developer / MCP Connectors / Custom Actions**.
3. Add a new MCP Server connection:
   - **Server Type**: `Streamable HTTP / SSE`
   - **Endpoint URL**: `https://<your-tunnel-url>/mcp`
   - **Authentication**: `Bearer Token`
   - **Token**: `<Your-AIBridge-API-Token>`
4. Save and verify tool discovery. ChatGPT should discover all 15 logical AIBridge tools:
   - `ping_bridge`
   - `get_bridge_status`
   - `list_projects`
   - `get_project`
   - `get_project_progress`
   - `get_current_phase`
   - `get_dispatchable_tasks`
   - `get_task`
   - `prepare_task_execution`
   - `dispatch_task`
   - `get_current_execution`
   - `get_execution`
   - `cancel_execution`
   - `get_review_package`
   - `get_git_evidence`

---

## 5. Acceptance Verification Checklist

1. Invoke `ping_bridge` from ChatGPT Web. Expect:
   ```json
   {
     "ok": true,
     "service": "AIBridge",
     "phase": "08",
     "version": "0.8.0",
     "mcpReady": true
   }
   ```
2. Invoke `list_projects` and select a target task.
3. Call `prepare_task_execution` to canonicalize ChatGPT instructions into an `ExecutionPromptPackage`.
4. Call `dispatch_task`. If the task requires a Human Gate, expect:
   ```json
   {
     "success": false,
     "errorCode": "HUMAN_APPROVAL_REQUIRED"
   }
   ```
5. Click **[APPROVE EXECUTION (HUMAN GATE)]** in the AIBridge WPF application.
6. Re-invoke `dispatch_task` from ChatGPT Web -> Dispatch succeeds!
7. Call `get_review_package` and `get_git_evidence` to inspect execution evidence and diffs.

---

## 6. Disconnection & Token Revocation

When finished:
1. Disconnect the MCP connector in ChatGPT Web.
2. Stop the local tunnel.
3. Click **[REGENERATE]** token in AIBridge WPF UI to invalidate the previous access token.
